# Visual Styles

## Place Style

The place style is based on the provided environmental reference.

### Visual characteristics
- Deep cobalt and electric-blue palette
- Large fluffy cumulus clouds
- Bright cloud edges
- Mirror-like water reflections
- Sparkling atmospheric particles
- Strong landmark or architectural focal point
- Dramatic but calm cinematic atmosphere
- Highly detailed background painting
- Soft volumetric light
- Vertical wallpaper-oriented composition

### Place style block

```text
anime landscape painting, cinematic wide shot, deep cobalt and electric blue color palette, giant fluffy cumulus clouds with glowing edges, mirror-like water reflection, sparkling light particles floating in the air, dramatic sky, highly detailed background art, soft volumetric light, vertical wallpaper composition, masterpiece
```

## Character Style

The character style is based on the provided character-sheet references.

### Visual characteristics
- Loose sketchy concept-art appearance
- Rough digital sketch
- Visible dark ink/pencil lines
- Painterly saturated colors
- Glowing energy effects
- Dynamic action poses
- Motion lines
- Cute/chibi-leaning proportions
- Fierce expressions
- Large shiny eyes
- Small character gear
- Warm beige paper texture
- Purple painted ground/shadow strokes
- Handwritten graphic labels
- Character-sheet presentation

### Character style block

```text
loose sketchy digital concept art, rough ink linework with visible pencil sketch lines, painterly bold saturated colors, glowing energy effects, dynamic action pose, motion lines, cute chibi-leaning proportions with fierce expression, big shiny eyes, warm beige textured paper background, purple painted ground shadow strokes, handwritten label text, character sheet with multiple pose studies
```

## Style Rule

The reference images define the visual direction. The system describes that direction using text rather than copying exact artwork.
