## Important Boundary

The research supports the project but does not automatically become a new feature.

For example:

- Shape-ratio mathematics is research guidance, not a required version-1 calculation.
- Prompt weighting is optional.
- Negative prompts are optional.
- Compatibility metadata is a future enhancement.
- Platform-specific parameters are future enhancements.

The core project remains a simple random prompt generator.
